## What changed

**`styles.css` — `:root`**
- Replaced the old neutral palette with the rivr-web brand tokens, defined as the
  canonical names from the spec (`--color-background #F5EDE2`, `--color-accent
  #C8945D`, `--color-secondary #7A8C6E` sage, `--color-walnut #8B5A3C`,

## Judgment calls
- **Headlines → Cormorant.** The current design used Inter headlines with Cormorant
  *italic accents only*. Spec item 2 ("Headings use Cormorant Garamond") + the
  "editorial magazine" goal + rivr-web's `--font-display` all point to full serif
  headlines, so I switched them and relaxed the negative letter-spacing (tuned for
  Inter) to suit the serif. This is the single biggest visual shift — screenshots
  look right, but flag for review if a mixed serif/sans headline was intended.
- **Button divergence from rivr-web.** rivr-web's actual button uses
  `transition-colors` to a *lighter* accent-hover with no lift. Phase-1 spec
  explicitly mandates hover→walnut + `translateY(-1px)` + shadow + `all 200ms ease`,
  so I followed the spec, not rivr-web. Primary text flips to cream on hover
  (charcoal-on-walnut would fail contrast — spec didn't specify hover text color).
- **"No inline hex" scope.** Tokenized every brand/surface color. Left as literals:
  (a) alpha-only elevation shadows / scrims / glass tints (`rgba(0,0,0,…)`,
  `rgba(255,255,255,…)`, dark modal `rgba(10,10,10,…)`) — these are effects, not
  palette; (b) the Mac traffic-light dots on the `BrowserFrame` chrome
  (`#FF5F57/#FEBC2E/#28C840`); (c) third-party integration brand colors in the
  product calendar mockup (Google `#1A73E8`, Acuity `#5BC0EB`, Vagaro `#FF7A59`,
  Boulevard `#0A0A0A`). The hero "confirmation" dot was moved off the generic green
  onto brand **Sage** per the palette's "positive states" note.
- **Elevated surface = warm white `#FCFAF6`**, not pure `#FFFFFF` and not
  rivr-web's darker `#E8DCC8` (that token reads as a fill, too heavy for the many
  card surfaces here). Cards still lift off the cream without going stark-white.
- JSX inline section colors (e.g. `product.jsx` appointment category swatches) were
  left alone — section-level, belongs to a later phase.
